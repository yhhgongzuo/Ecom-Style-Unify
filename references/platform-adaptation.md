# 平台能力与生图接口适配

这是运行时适配规则，不是内置所有厂商 SDK 的万能接口库。每次换平台、账号或工具版本时重新探测；不得把平台名称当作能力证据。用户明确指定平台、模型或预算时优先遵循。本技能自动选择模型不代表允许开通付费服务、购买额度或使用未授权账号。

## 1. 先确定实际运行能力

读取当前工具清单、工具参数说明、已连接服务及平台官方模型目录；只有信息缺失时才查询该服务的当前官方文档。不要扫描无关文件、聊天记录或凭据。工作记录保存平台、工具名、可选模型、信息来源和核实日期。

逐项检查：读取和保存附件；查看图片及局部；文字生图；带参考图编辑；至少两张有角色区别的参考图（正式场景 A/B），以及三张参考图编辑（后续排版 A/B/C，产品补图可能更多）；输出文件获取；实际尺寸读取；EXIF 校正、白底合成、缩放和裁切；异步任务查询、并发和失败处理。按本次实际输入数确认上限，不能只看是否写着“支持图片”。

- Codex 或其他本地代理：使用平台已提供的工具/连接器；Python 3 + Pillow 可运行图片助手。遵循该宿主发现技能的位置和当前工具规则。
- 豆包等聊天平台：先检查实际附件、技能/智能体配置、文件和图像编辑能力。支持导入技能则按官方格式安装；只支持智能体指令/知识文件时，按其容量和接口保存完整 SKILL.md、本文及辅助脚本，并核实能重新读取。转换格式不能丢失操作约束。
- 只有普通聊天、无持久配置时，只能在当前会话加载工作流，不称永久安装。若平台连 ZIP 都不能读取，明确请用户解压后提供 SKILL.md 和本文件；若缺少脚本或等效文件处理能力，不能承诺完整执行。
- Python 不可用时，可以用已验证的原生图片工具完成同样的 EXIF/透明白底/4096 限长边/尺寸读取/裁切操作；原图不可覆盖。原生工具也不能完成时，报告具体阻塞阶段。不能将未处理附件直接送入生成来伪装兼容。

## 2. 自动选择效果优先的模型

“最高智能/效果最好”解释为：在当前账号已接入且可调用的候选中，优先满足本任务效果要求的最高质量配置，而不是宣称全行业第一。不要写死某厂商或某个容易过时的模型 ID。

先淘汰无法满足当前阶段参考图数量、编辑能力、目标比例、图片读取/输出或权限要求的候选。对其余候选，依据当前官方能力说明、当前工具暴露的质量档位和本任务已有验收结果，优先比较：
1. 产品身份、结构、固有颜色、构图与多图角色遵循；
2. 原文案、数字、单位、中文/英文文字的准确绘制；
3. 跨图风格、字体和设计元素的一致性；
4. 商业摄影质感与可交付分辨率。

选择工具实际支持的最高质量档位；相近效果优先当前原生、已认证的接口。不得为了速度选低质量快照版。分辨率按用户目标和接口实际允许值设置，不等同于模型智能，也不把插值放大说成细节增强。资料不足时说明“选用当前可用且符合任务能力要求的质量优先选项，无法证实跨模型最优”。

如果原生工具只暴露一个模型或不允许指定 model，就使用其实际能力，不发送虚构的模型参数，不声称已经切到另一模型。若更适合的模型仅在未接入/未授权的服务上，说明可用范围；不能凭空取得接口。模型自动选择不新增付费对比测试，利用正常生成与原有修复额度检验效果。

尽量固定一个模型完成整套。确需分阶段使用不同模型时记录分工，并加强跨阶段一致性检查。限流优先等待/降并发，不静默切换低质量模型。切换若会重做已通过图或增加原定修复额度，先说明范围并取得确认。

## 3. 把统一任务映射到真实接口

内部记录统一字段：图号、阶段、尝试编号、准确提示词、有序参考图及 A/B/C 角色、目标宽高比与尺寸、透明背景要求、质量偏好、输出路径。它是工作记录，不是给任意接口直接发送的 JSON。

每次依据实际工具 schema 或当前官方 API 文档逐字段映射：
- 新图阶段只传文字，不带最近图片或附件历史。
- 编辑阶段传入预处理后的参考副本，并保留顺序和角色。接口接受本地路径、上传文件 ID、URL 或 base64 中哪一种就用哪一种；不能把本地路径字符串当作远程接口已能读取的图片。
- 必须上传时只上传本任务必要图片到已选的授权生成服务；不借助公开图床，不把产品图发布为公开链接。上传后的文件 ID/可访问 URL 与本地图号一一记录。
- `model`、质量、尺寸、负面提示词、种子等只有文档明确支持才传。平台不暴露的参数不臆造；能力不足导致无法按流程编辑时报告阻塞。
- 若只支持单张参考或无法区分多图角色，先找其他已授权且满足要求的接口；不能静默把 A/B/C 拼接成一张、删除关键参考或退回纯文生图。
- 异步 API 保存任务 ID，按实际状态/重试间隔查询，取回最终结果并绑定图号。超时但状态未知时先查任务，不重复提交。签名 URL 到期时用任务接口重新获取，不当作生成失败重做。
- 并发为 min(6, 当前平台/工具/账号实际允许上限)。宿主强制串行则串行；没有 Promise 或 yield_control 时使用可用的任务队列机制，不照抄 Codex 代码。失败调用计入 SKILL.md 的原有阶段修复额度。
- 返回图片后实际保存、解码和视觉验收。结果展示方式、等待方式和工具强制要求以宿主为准；没有内部预览隐藏选项就不能承诺隐藏小样。

接口凭据仅使用已有安全连接或环境配置。不得要求在聊天中粘贴 Key、将密钥写入技能/输出文件、复用分享者账号或修改平台安全设置。确需新接口配置时给出缺项和官方配置方式；配置完成前只推进不依赖它的工作。

## 4. 安装与可执行状态分开报告

分别报告：文件是否安装并可被发现；图片助手或等效操作是否通过；当前生成工具和选择理由；本次可支持的参考图数量/并发；尚缺能力。仅复制成功不能称整个流程已可用。没有真实跨平台生图验收就标记“尚未在该平台实测”。所有平台均保留原图风格选择、产品补图选择、逐图原文还原、阶段验收和失败次数规则。
